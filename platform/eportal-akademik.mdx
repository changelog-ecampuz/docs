### <Icon icon="newspaper" /> **Fitur Baru Modul Capaian Pembelajaran Lulusan (CPL Mahasiswa)**

**Navigasi Submenu Capaian Pembelajaran Portal Mahasiswa**<br />Menambahkan submenu khusus Capaian Pembelajaran pada dasbor utama mahasiswa.

**Monitoring CPL via Progress Bar & Rekomendasi**<br />Visualisasi progres kelulusan CPL dengan indikator Progress Bar dan saran perbaikan capaian.

**Tabel Analisis Detail & Spider Web Chart**<br />Tampilan tabel nilai CPL yang terhubung langsung dengan grafik Spider Web Chart interaktif.

**Deskripsi Interaktif Indikator CPL**<br />Penyediaan keterangan deskripsi CPL yang dapat diklik untuk memahami target pembelajaran.

**Unduh Laporan CPL Format Excel**<br />Fasilitas cetak dan ekspor rekapitulasi CPL mahasiswa ke format file Excel.

**Filter Periode Akademik Capaian Pembelajaran**<br />Penyaringan data CPL berdasarkan semester dan tahun akademik yang diinginkan.

**Pengaturan Visibilitas Submenu CPL (OBE On/Off)**<br />Fitur penyesuaian tampilan submenu CPL berbasis konfigurasi status pengaktifan OBE kampus.

### <Icon icon="newspaper" /> **Fitur Baru Modul Evaluasi Formatif OBE di Portal Web**

**Lihat Nilai & Feedback Tugas Perkuliahan**<br />Mahasiswa dapat memeriksa rincian nilai beserta umpan balik dosen pada setiap tugas Evaluasi Formatif OBE.

**Dashboard Grafik Pencapaian Evaluasi Formatif**<br />Dasbor visual grafik pencapaian evaluasi formatif untuk memantau perkembangan belajar.

**Pengajuan Remedial dari Sisi Mahasiswa**<br />Mahasiswa dapat mengajukan dan mengunggah tugas perbaikan remedial secara mandiri.

**Tab Capaian Evaluasi Formatif Dosen**<br />Dosen dapat melihat grafik pencapaian evaluasi formatif kelas secara menyeluruh.

**Pembuatan Sesi Remedial oleh Dosen**<br />Dosen dapat mengonfigurasi dan membuka sesi tugas remedial bagi mahasiswa.

**Pengecekan Status Aktif Evaluasi OBE Formatif**<br />Sistem melakukan Pengecekan status aktif modul sebelum menampilkan submenu evaluasi OBE.

### <Icon icon="newspaper" /> **Fitur Baru Tambahan & Integrasi LMS**

**Opsi Pengosongan Nilai (Set Null) Nilai Relatif**<br />Penambahan fitur set null pada Pengelolaan Nilai untuk mengosongkan kembali nilai yang sudah diinput jika terjadi revisi.

**Tombol Catatan Pembaruan (Changelog Button)**<br />Penambahan tombol dan penanda fitur changelog bagi pengguna untuk melihat riwayat rilis update aplikasi.

**Tombol & Riwayat Aksi Sinkronisasi Nilai LMS**<br />Penambahan konfigurasi tombol dan pencatatan riwayat aksi saat melakukan sinkronisasi nilai dari Moodle LMS.

### <Icon icon="settings" /> **Revisi & Perbaikan Sistem**

**Penyesuaian Opsi Default Presensi Mandiri Dosen**<br />Mengubah pilihan default presensi dosen dari sebelumnya wajib IP Address menjadi lebih fleksibel.

**Pengaturan Lock Submenu Evaluasi Formatif OBE**<br />Penyesuaian kuncian akses submenu Evaluasi Formatif OBE berdasarkan lisensi paket OBE kampus.

**Presensi Manual Multi-Halaman Lebih Akurat**<br />Pengisian presensi manual di halaman pertama tidak lagi membuat status mahasiswa di halaman berikutnya terisi '-' secara tidak sengaja.

**Pengisian Tanggal SKPI Tab Bahasa Internasional**<br />Pembaruan tanggal SKPI pada tab Bahasa Internasional dapat disimpan lancar tanpa pesan kesalahan 'invalid date'.

**Fleksibilitas Pengaturan Jam Mulai & Selesai Tugas/Ujian**<br />Dosen dapat mengubah jam mulai dan selesai pada tugas perkuliahan atau ujian kelas tanpa notifikasi waktu tidak cocok.
